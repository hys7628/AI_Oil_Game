지시문 : 게임 요소를 활용한 정유-석유화학 산업 공부용 웹사이트를 만들 것.
코딩 방식 : netlify에 배포할 거고 streamlit이 아닌 html, css, javascript를 활용할 것
웹사이트 형태 1 : 넥슨 메이플스토리의 RPG 게임 UI/UX를 그대로 사용할 것. 산업 용어와 매칭 되는 몬스터를 생성하고 그 몬스터를 퇴치하면 비밀의 두루마리가 등장하면서 용어에 대한 설명이 나옴. 
웹사이트 형태 2 : 몬스터 잡을 때마다 경험치 상승. 몬스터 3마리 잡을 때마다 1레벨씩 상승. 최대 레벨은 500으로 설정할 것.
웹사이트 형태 3 : NPC를 한 명 설정할 것(oil.jpg)
